# 全站审查记录（2026-10-15）

本轮以 `57081c7f` 为基线。该版本已经包含磁盘容量与百分比匹配、设置敏感值占位符、WebKit 全屏复制修复，本轮保留这些实现。

## 覆盖范围与方法

审查范围为仓库内 58 个页面、195 个 API 路由，以及它们调用的服务、异步任务和实时连接入口。页面源代码检查、权限目录审计、单元／数据库验证和浏览器流程分别记录；自动化浏览器通过不能证明每种真实 VPS、输入法或外部提供商都已实机验证。

## 本轮修复

| 问题 | 修复行为 |
| --- | --- |
| 仪表盘对所有已登录用户读取 VPS、命令、审计等数据 | 每类查询使用对应权限；定时任务统计与业务页面统一使用 `command:read` |
| 审批、模板、定时任务及文件搜索／WebDAV／同步页缺少入口读权限 | 在执行页面数据查询前调用统一页面权限检查；告警规则页检查 `notification:manage` |
| 多个模块预加载无权读取的服务器、存储或 Playbook 下拉选项 | 按模块操作能力和关联资源读权限加载选项；存储表单 Server Action 单独验证写入／节点管理权限 |
| AI Ops 读接口已限平台管理员，写接口却可被客户模板授权 | 配置、扫描、批准、执行统一复用平台管理员检查 |
| AI 跨服务调用重建会话时丢失显式权限 | 保留身份模板的 grants，包括显式空权限数组，避免回落到旧角色权限 |
| AI 待确认列表不跟随当前客户，确认创建失败后状态卡住 | 按当前客户和发起人查询；确认命令的条件更新保留客户约束；失败写入终态及错误，命令请求使用稳定幂等键 |
| Windows SSH 命令面板展示 Linux 命令 | 节点操作系统沿多标签终端传到面板，Windows 提供 cmd／PowerShell 通用命令 |
| VPS 状态页为计数加载完整配置，且超过 500 条时数量被截断 | 使用同一资源范围的数据库 count，无须加载密钥与连接配置 |
| 下载限速接受小数、负数或过大值 | 创建、单任务调整和全局调整统一限定为 0–10,000,000 的整数 KB/s；0 表示不限速 |

## 真实环境边界

手机中文输入法、实际 Windows RDP／OpenSSH、外部云与 AI 提供商需要相应设备及连接才能完成端到端实测。本轮浏览器测试中的模拟 SSH／RDP 连接会单独标明，不能当作真实远端主机的验收结果。

SSH 密钥选择器的超大数据量分页仍属于扩展需求（历史记录 F-05），本轮没有将其描述为已完成。
