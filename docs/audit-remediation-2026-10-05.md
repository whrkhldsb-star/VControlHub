# 深入检查与修复记录：2026-10-05

基线为 `ff0ff4db`（PR #3）。本轮在独立 worktree 和专用 PostgreSQL 数据库中复现问题、修复并验证；未使用生产数据运行测试。没有新增数据库迁移。

## 修复的问题

### 认证和安全设置

- 待完成二次验证的登录令牌绑定密码指纹和会话撤销版本。密码重置、禁用账号、全设备退出后，旧的待验证登录无法继续换取完整会话。
- 密码验证时捕获凭据状态，经过异步验证后仍只允许为该状态签发会话；不把旧密码的验证结果绑定到期间重置的新凭据。
- 密码更改使用原密码散列、会话版本及未禁用状态作为更新条件，并同时递增会话版本。管理员的并发禁用、重置或撤销操作不会被覆盖。
- 二次验证启用、禁用和恢复码重建共用有条件的原子更新。验证器设置与旧会话撤销在同一次 SQL 写入中完成；并发启用只允许一个请求成功。
- 二次验证修改还校验 API 登录检查时保留的凭据状态，防止登录检查通过后、读取验证器配置之前发生的会话撤销被新的 cookie 覆盖。该状态只保存在服务端，不进入页面 props 或 cookie。
- 刷新当前浏览器的 cookie 时，继续核验本次写入的凭据状态。恢复码重建现在也会撤销其他会话，当前浏览器获得新 cookie。

已有完整会话的签名格式保持兼容。升级前生成的待完成二次验证令牌需要重新登录，其原有效期仅五分钟。

### 文件、存储和分享

- PostgreSQL 的 `LIKE` 会把 `%`、`_` 和反斜杠解释为模式语法，Prisma 的 `startsWith` 同样受影响。新增共用字面量转义，覆盖删除、移动、复制、回收站权限、目录分享、配额统计、历史版本清理、SFTP/WebDAV、归档下载及工作区列表。
- 真实数据库测试复现并阻止了兄弟目录被误软删除、分享和回收站显示未授权的兄弟目录元数据、兄弟目录大小被错误计入配额。
- 分块上传将状态复核、文件重命名和已收分块记录更新置于同一个数据库行锁保护范围内。重复分块也必须取得该锁，不能在最终提交开始后覆盖分块内容。
- 图片上传先取得最终提交资格，再拼接和解码图片。竞争失败的请求不会读取或清理另一请求正在处理的分块。
- 存储直连网关健康探测主动取消未消费的响应体，释放固定 DNS 连接资源，包括网关始终不结束响应体的情况。

数据库事务无法与文件系统组成分布式原子事务。本轮保证最终提交与分块重传之间的互斥，保留已有失败处理和补偿流程。

### 后台任务与远程桌面

- 后台任务心跳新增独立租约截止计时。数据库心跳一直不返回时仍会中止在途操作；续租有效期从请求发起时计算，迟到的响应不会恢复已经丢失的租约。
- 心跳失败回调自身抛错也不能阻止取消信号发出，完成后清理计时器。
- 已建立的 RDP 隧道增加权限复核截止监测。权限查询停滞超过五秒后关闭隧道，即使管理员配置了不限空闲时间，也不能无限跳过权限复核。

保留 Web、后台 Worker、SSH/RDP 网关的进程隔离。命令任务仍只尝试一次，保留执行者权限复核、Agent 认领后不转 SSH 重放、主机指纹校验及独立取消监测。

### 备份恢复

- 修正 Node 文件恢复入口忽略命令行目标目录的问题。
- 完整恢复在覆盖任何文件前检查数据库恢复确认、目标配置和客户端；提前固定数据库连接，防止归档中的旧 `.env.local` 改变恢复目标。
- 支持归档中 `./database.sql.gz` 的命名，并完整扫描归档索引；不再使用只保留最后 1 MiB 的诊断输出进行安全校验。
- SQL 输入或解压失败时清理流和子进程，失败路径保留临时目录清理。
- Linux 的数据库/完整恢复入口调用共用 Node 实现；原有命令行参数保留。
- Linux 备份入口也统一调用共用 Node 实现，避免失败数据库导出留下看似完整的文件，拒绝覆盖同名旧备份，并将数据库密码从进程参数移入子进程环境。

Linux 兼容脚本需要部署所用的 Node 可执行文件在 `PATH` 中。恢复仍是管理员主动执行的破坏性操作，数据库和文件之间没有跨资源事务；应停写、先备份，并使用隔离环境演练。外部存储目录仍按 `external-data.json` 由管理员映射，不会自动写回归档中的绝对路径。
