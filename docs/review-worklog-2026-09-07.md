## 已确认的基础问题

1. `globals.css` 1,799 行，包含多轮覆盖规则。`article`、`role=dialog`、`rounded-xl.border` 等宽泛选择器承担隐含组件样式，造成颜色语义、间距和布局相互覆盖。
2. 同一控件混用 Tailwind、共享类字符串、data 属性规则和全局补丁。输入框焦点、按钮主色、面板圆角、表格表头有重复定义。
3. 页面与表单区段普遍呈现嵌套卡片、背景渐变、描边和阴影，削弱操作层级；标题字号和字距也不统一。
4. 上轮页面宽度检查无法发现被 `overflow-x-clip` 隐藏的内部内容，需要增加元素裁切、长文本、焦点、弹窗和多语言验证。
5. 文件首屏与列表 API 重复大量逻辑，均从受限概览构建全目录树后筛选，导致大文件库漏项且重复读取无关数据。
